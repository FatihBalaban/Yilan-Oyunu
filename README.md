# BGT 132 Final Projesi: Nesne Yönelimli Yılan Oyunu

## 📝 Proje Hakkında
Bu proje, **OSTİM Teknik Üniversitesi** BGT 132 Yazılım Geliştirme Teknolojileri dersi final ödevi kapsamında geliştirilmiştir. Projenin temel amacı, klasik yılan oyunu mekaniklerini modern Yazılım Geliştirme süreçlerine ve **Nesne Yönelimli Programlama (OOP)** prensiplerine uygun olarak yeniden inşa etmektir.

## 🎯 Proje Amacı
* **OOP Prensiplerini Uygulamak:** Kalıtım (Inheritance), Çok Biçimlilik (Polymorphism) ve Kapsülleme (Encapsulation) kavramlarını kod üzerinde göstermek.
* **Modüler Tasarım:** Kodun tek bir dosyada değil, işlevlerine göre ayrılmış (core, services, ui) bir klasör yapısında sunulması.
* **Hata Yönetimi:** Uygulama içerisinde oluşabilecek çalışma zamanı hatalarını `try-catch` blokları ile kontrol altına almak.

## 🚀 Kurulum ve Çalıştırma Talimatı
Bu proje modern JavaScript modülleri (`ES6 Modules`) kullanılarak geliştirilmiştir. Bu nedenle dosyalar doğrudan çift tıklanarak çalıştırıldığında tarayıcı güvenlik politikaları (CORS) nedeniyle hata verebilir[cite: 2].

**Çalıştırmak için şu adımları izleyin:**
1. Proje klasörünü **VS Code** ile açın.
2. VS Code içerisindeki **"Live Server"** eklentisini kurun.
3. `src/ui/index.html` dosyasına sağ tıklayıp **"Open with Live Server"** seçeneğini seçin.
4. Tarayıcıda açılan ekranda zorluk seviyesini seçerek "Oyuna Başla" butonuna basın.

## 🛠️ Kullanılan Teknolojiler
* **Dil:** JavaScript (ES6+), HTML5, CSS3[cite: 2].
* **Mimari:** Nesne Yönelimli Programlama (OOP) ve Modüler Sistem Tasarımı[cite: 2].
* **Versiyon Kontrol:** Git & GitHub[cite: 2].
